# ชุดทดสอบภาระงานด้วยตนเอง

ชุดข้อมูลสมมติ 180 เคส สำหรับหน้า `public/teacher-dashboard.html` (อ้างอิงโค้ด 29d1e00) ไม่มีข้อมูลบุคคลจริง

**ยังไม่ได้ทดสอบผ่านเบราว์เซอร์ให้:** ทุกเคสมีสถานะ NOT_RUN สำหรับคุณทดสอบเอง ตัวเลขคาดหวังได้ตรวจเทียบกับชุดน้ำหนักที่ถอดจาก PDF และฟังก์ชันคำนวณแล้ว ไม่ใช่ผลยืนยันว่า UI ผ่าน

## เตรียมทดสอบ

1. เปิดเว็บด้วยวิธีเดิม แล้วกดไอคอนข้อมูลอาจารย์ → กรอกภาระงาน หรือเปิดหน้า teacher-dashboard.html โดยตรง
2. รีเฟรชเพื่อเริ่มจากรายการว่าง; แนะนำเปิด Console ไว้ดูข้อผิดพลาด
3. ทุกเคสใช้ภาค **2** ปี **2567** ชื่อรายการ **ทดสอบภาระงาน + รหัสเคส** เว้นแต่เคสนั้นระบุอย่างอื่น
4. เลือกหมวด → ประเภทหลัก → ประเภทย่อย → บทบาท ตามตาราง กรอกเฉพาะช่องที่ปรากฏ
5. ชื่อนักศึกษาตัวอย่าง: **นายทดสอบ หนึ่ง** และ **นางสาวตัวอย่าง สอง** คนละบรรทัด เฉพาะเคสที่ระบุว่าช่องชื่อแสดง
6. ใช้ลิงก์หลักฐาน `https://example.com` หรือเว้นว่าง เลือกไฟล์ PDF/PNG ที่ไม่ใช่ข้อมูลจริงของบุคคลสำหรับเคสไฟล์
7. กดเพิ่ม แล้วตรวจคะแนนบนการ์ด; ช่องท้ายตารางให้กรอก PASS / FAIL พร้อมอาการ ไม่ต้องแก้ช่องคะแนน
8. หมายเหตุ: เคสของบทบาทเดียวกันในงานอาจารย์ที่ปรึกษาอาจชนกฎกันซ้ำ ให้ลบรายการเดิมก่อนหรือเปลี่ยนภาค/ปี

## ลำดับที่แนะนำ

- เริ่ม F01–F05, F15–F17, F22–F23, F30 เพื่อทดสอบเส้นทางหลัก
- จากนั้นลอง N01–N31 เพื่อตรวจสัดส่วนและค่าขอบเขต
- ไล่ W001–W115 เพื่อเช็กทุกบทบาท รวมตำแหน่งรอประเมิน 6 แบบ
- ปิดท้ายด้วยเคสไฟล์ หน้าจอมือถือ และ F25 (รีเฟรชทำให้ข้อมูลหาย)

## D. ข้อจำกัดที่ต้องแยกจากบั๊ก

- **G01 สิทธิบัตร ตัวเลือกที่ 4:** งานวิชาการ → สิทธิบัตร / สิ่งประดิษฐ์ → เปิด dropdown ชนิดงาน → ตัวเลือกข้อความถูกตัดใน PDF ถูกปิด ไม่สามารถเลือกหรือคำนวณได้
- **G02 คะแนนพิเศษ:** เลือกหมวดคะแนนพิเศษ → ไม่มีเกณฑ์ / คะแนน —; ปุ่มเพิ่มรายการถูกปิด
